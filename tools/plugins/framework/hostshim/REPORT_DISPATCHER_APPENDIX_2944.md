## 4. 受入 3: B 群 13 ID と共通後処理 0x13281af

- B 群の出口 (vcall → `jmp`/`jne` で 0x13281af): 0x04 (0x1318f4c)・0x0a (0x1319490)・0x1e (0x131bba4)・0x23 (0x131bd0f)・0x49 (0x1321dd2)・0x57 (0x13193eb)・0x5d (0x132282f)・0x5e (0x1322893)・0x5f (0x13228cc)・0x60 (0x13228eb)・0x67 (0x1322b69)・0x69 (0x1322ba7)・0x6a (0x1322be7)。各 vcall から reach で読み出し 0x1328a38 に届き、格納は 0 件 (373〜374 節点)。ID 経路の最後の格納は初期化 `0x131873f` (A-2 の 229 ID と一致)。**応答 = 0 で確定**。

- ブロックへの入口 (範囲外から範囲内 `[0x1328057, 0x13281af)` への直接 jcc/jmp) は **4 件**。関数範囲 `[0x13173a0, 0x1330000)` を capstone で線形逆アセンブルして全 jcc/jmp を照合した (間接 jmp は 0 件)。

  - `0x1318ccf` `jmp 0x132813e` (ID 0x6d の `sub eax,1`・`jne` 不成立の後)
