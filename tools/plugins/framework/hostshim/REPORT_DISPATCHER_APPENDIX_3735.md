## 2. callee 母集合と数え方

- 基準 run: `HS_DISP_PATH=1` の全 256 ID (既定・callee 戻り値 0)。73 秒。`distinct (rax, path) = 109` / unmapped 61 ID・5,340 件・200 組・197 ページ (PLG-P0b-2 の既定値と一致)。
- callee 母集合: 基準 run の `callout_at` に現れる VA は 82 件。そこから `0x40fe90` を除いた **81 件**。
- 個別 run: callee ごとに、その callee を `HS_DISP_RET_SPEC=<VA>:one` にし、**基準で同じ callee を呼ぶ ID だけ**を実行した (計 1,282 組のうち、各 callee の ID 数の和)。
  - 理由: 戻り値を変えても、その callee を呼ばない ID の実行は基準と同一になる。除外してよい根拠は、同じ ID 集合で `0x40fe90` を全 256 ID と比べた結果 (下の検算) による。
  - 81 件の合計 514 秒 (n=1)。
- 検算 1 (部分実行の妥当性): `0x40fe90` を全 256 ID で実行した run と、基準 + 部分 run の結果 (`m_40fe90.json`) は全 256 ID で `(rax, path_hash)` が一致 (差 0 ID)。
- 検算 2 (組合せ効果): 全 82 VA を同時に `one` にした run (72 秒) と、個別 82 件の和集合を比べた。差は 0 件 (下の §3.2)。
- 202 集合 = `hs_store_cov.py` の `no_case_store` (共通初期化の格納だけを実行し、共通終端 `0x1328a4a` に到達した ID)。基準で 202 件。`rax == 0` の 245 件とは別の定義。
