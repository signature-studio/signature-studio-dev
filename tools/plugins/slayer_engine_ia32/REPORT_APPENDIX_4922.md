## 1. 結論

- 受入 1 (辿るポインタの位置): **引数 a0・a1 が指す先**。 窓 (ecx の 0x540 B) の中ではない。 §2。
- 受入 2 (segfault せず終わる): **既定 harness の入力で native rc 0・wasm rc 0** (2000 行)。 §3。
- 受入 3 (native と wasm の全行一致): **2000 / 2000 行で全項目一致** (eax・st0・st0d・d・mem・stk・wide)。 不一致 0 件。 §3。
- 注意: issue 本文の「窓の中に有効な番地」は、この関数には当たらない。 窓の中の値は分岐の旗 (`[ecx+0x18]`) だけで、番地は引数から来る。 入力は、引数の指す先を広い範囲 (`ecx = 0x10700000` の wide 領域) に置いて作った。
- ゲート `TARGETS` には入れていない。 判定器 (`x87_fn_diff.py:413`) の非自明性は OBJ 窓が変わること (`effect > 0`) で満たす (OBJ 窓が変わる。 eax は 1 種類のみのため、eax の条件は満たさない。 関数の戻り値 eax・ST(0) は 0 の 1 種類のみ)。 変化は広い範囲と OBJ 窓で観測する。 ゲートに入れるかは #4924 の判定設計に合わせて決める。

## 2. 辿るポインタの位置 (受入 1)

lift 出力 (`work/lift_text/ott_lifted.c` の `f_100096d0`) を読んだ結果。 `esp` は関数入口の値で、引数は `[esp+4]` 以降。

| 項目 | 命令 (VA) | 位置 | 窓 (0x540 B) 内か |
|---|---|---|---|
| a0 (ポインタ S0) | `100096e8` `mov edx, [esp+0x14]` → `100096f4` `mov eax, [edx]`・`100096f6` `mov esi, [edx+4]` | 引数 a0 が指す先 | **外** |
| a1 (ポインタ S1) | `100096ec` `mov edi, [esp+0x18]` → `100096f9` `mov edx, [edi]`・`100096fb` `mov edi, [edi+4]` | 引数 a1 が指す先 | **外** |
| 件数 a2 | `100096f0` `mov ebx, [esp+0x1c]` | 引数 a2 (ループ回数) | — |
| 旗 | `100096d1` `mov al, [ecx+0x18]`・`100096d7`〜`100096d9` `je` | 窓の `+0x18` の 1 byte | 内 (旗のみ。 番地ではない) |

- 読んだ値 (X・Y) と書込み先 (Z・W) は、S0・S1 が指す 2 語の番地から作る。 ループ本体 (`L_100097f0`) は `esi`・`edi` を 4 ずつ進め、`[edi-4]` に書く。
- `ecx+0x3c`・`ecx+0x40`・`ecx+0x44`〜`ecx+0xd0` などの窓への読み書きは、旗が 1 のときだけ通る。

## 3. 測定 (受入 2・3)

測定: `python3 lift_text.py && python3 probe_96d0_4922.py` (`work/96d0_4922/`、seed 4922、2000 行)。

| 項目 | 値 |
|---|---|
| native rc / wasm rc | 0 / 0 |
| 行数 native / wasm / 入力 | 2000 / 2000 / 2000 |
| 全項目一致 (eax・st0・st0d・d・mem・stk・wide) | **2000 / 2000** |
| 項目ごとの不一致 | 0 (7 項目すべて 0) |
| 旗 = 1 の行 (ループが回る) | 1509 / 2000 |
| 広い範囲 (wide) が変わった行 (native) | 1509 / 2000 |
| OBJ 窓が変わった行 (旗の語を除いて比較) | 1509 / 2000 |
| eax の種類 | 1 (0 のみ。 この関数は戻り値を返さない) |

- 入力: 行ごとに S0・S1 を wide 領域の別々の slot に置き、その slot に X・Y・Z・W を置く (`@addr=hex`)。 件数 a2 は 1..8。 旗は 3/4 を 1、残りを 0 にした。
- 非自明性: 旗 = 1 の 1509 行は、wide と OBJ 窓の両方が変わる。 旗 = 0 の 491 行は変わらない (分岐の両側を通る)。 wide の変化のハッシュは 1510 種類 (行ごとに違う)。
- 再現は 2 回行った。 一度目は OBJ 窓の変化の数え方を誤っていたため、比較を旗の語を除いた初期値との突合に直した (`expect()`)。 二度目 (コミット済み HEAD) の数値は上表のとおり。
- 測定時間: `lift_text.py` と `probe_96d0_4922.py` の合計 real 41.86 s (load1 0.30 時点)。 probe 単体は real 26.08 s (load1 0.07 時点) と 38.24 s (load1 0.07 時点の別回)。
