## 2. 入力 (wide_patch)

逆アセンブル (`0x10003fe0`): ループ 6 周 (`ecx += 0x520d08`、周ごとに `ecx += 0x80198`)。 書込み経路は `byte [ecx+0xc] != 0` かつ `int32 [ecx+0x80174] > 0` のときだけ入る (`0x10004038`〜`0x1000404d`)。

`gen_rows` の `wide_patch` は、各周 k の base = `ECX_HI + 0x520d08 + k*0x80198` に次を行末の書込み (`@addr=hex`) で指定する:

| 書込み先 | 値 |
|---|---|
| `base-4`・`base`・`base+4` (float32) | 一様な乱数 (-100〜100) |
| `base+0xc` (byte) | 1・2・3・4・0・5 から選ぶ (0 と 5 で分岐を外す) |
| `base+0x80174` (int32) | 1・2・3・5・0・-1 から選ぶ (正で書込み経路、0/負で外す) |

- 行末の書込みは、OBJ 窓の後・広い範囲の snapshot の前に行う (native `x87_fn_native.c`・wasm `x87_fn_entry_wasm.mjs` の両方)。 形式は `@<addr>=<hex>`。
- 既存の行 (窓と引数) の形式は変えない。 書込みが無い行は従来どおり。
