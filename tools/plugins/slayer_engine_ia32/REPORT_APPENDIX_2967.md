## 1. 結論

- **m80 経路を op 表に入れた**: `fld tbyte ptr [eax]` (DB /5)・`fstp tbyte ptr [eax]` (DB /7)。 乱択 100,000 試行 (seed 1) の bit 一致は **98.44%** (98,443)。 m80 を含む試行は 94.40% (18,224/19,305)、含まない試行は 99.41% (80,219/80,695)。
- **f80↔f64 の往復**: 実 x87 と比べると、normal・zero・inf・qNaN・denormal は不一致 0。 不一致は sNaN の quiet 化 (実 x87 は quiet 化、lowered は保つ) と、denormal 域の二重丸め 2 件だけ (R1・R2、§4)。 lowered だけの往復 (R3) は sNaN 以外で bit 一致。 f80 側の往復 (R4) が戻らないのは、64bit 仮数の丸め・指数域外・非正規で想定どおり。
- **ネガティブコントロール (FAIL の数値)**: lowered の `fstp m80` を `fstp m64` に取り違えると、bit 一致は 98,443 → **95,443 (−3,000)**、m80 試行は 18,224 → 15,224 (−3,000)、slot 不一致試行は 563 → 3,572。 既存の fsub/fsubr 取り違え (`--nega`) も新しい op 表で 98,170 (−273) に下がり、検出力を保つ。
- **RC≠nearest の材料 (ADR D28 改訂は PM 判断)**: 同じ試行列で RC を 0/1/2/3 に固定すると、bit 一致は 98,601 (RC=0) → 87,533 (RC=1, −11,068)・97,145 (RC=2, −1,456)・97,283 (RC=3, −1,318)。 **ADR D28 制限 (5) の「RC は fist/fistp にだけ効く。 算術と fst m32 には効かない」は、この実測では成り立たない**。 fst m32 だけを含み、算術・fst m64・fist を含まない試行では RC=0 の 2,019 件が RC=1/2/3 で 1,783/1,764/1,774 件に減る (§3)。 RC=1 の不一致は 12,467 件 (100,000 − 87,533) で、そのうち 7,916 件は符号付きゼロだけの差 (数値の ulp は 0。 §3.2)。

## 2. 対象と方法

- **driver** (`x87_diff_main.h`): slot を 16 byte (lo・hi の 2 語) に拡張。 80bit 値は lo = 仮数 64bit、hi の下位 16bit = 符号・指数。 他の型は lo だけを使う。 出力の S は slot ごとに lo hi の 2 語 (16 語)。
- **入力の f80 値** (`f80_value()`): 通常の 64bit 仮数 48%・double に正確に入る値 (仮数 53bit) 15%・±0 5%・±inf 6%・qNaN 6%・sNaN 4%・非正規 6%・指数域外 10%。 有効な符号化だけを作る (非正規の指数は 0、正規は bit63 = 1)。 kind の重みは d:f:i:q:e = 4:2:2:2:2。
- **比較** (`compare()`): 試行が bit 一致 = F (FSW の C 値・TOP マスク後)・V (ST(0..d-1) の double bits)・S (slot 8 個) の全てが一致。 ulp 距離は `ulp_bits` (int64 の差)、別算法の検算 `ulp_step` (nextafter) と全件一致 (`ulp cross-check bad 0`)。
- **RC 固定** (`--rc-arith RC`): 試行列は RC の値だけが違う (RC の値を決める乱数を消費しない)。 RC=0 の結果が基準。 差は RC 由来として読む。
- **往復試験** (`x87_f80_rt.c`): 参照は実 x87 (`fldt`/`fstpl`・`fldl`/`fstpt`)。 類ごとに n = 100,000。 f80 の類は normal (指数は f64 の範囲内)・exp_out_of_f64 (指数が f64 の範囲外)・zero・inf・qnan・snan・denormal。

### 3.2 RC 固定の内訳 (`x87_crosscheck.py` (d)・同じ試行列の RC=0 と RC=1..3)

組は (算術, fst m32, fst m64, fist/fistp) の有無。 数字は bit 一致の試行数。

| 組 | 試行 | RC=0 | RC=1 | RC=2 | RC=3 |
|---|---:|---:|---:|---:|---:|
| 無し / 無し / 無し / 無し (RC で動く命令が無い対照) | 20,255 | 20,180 | 20,180 | 20,180 | 20,180 |
| 無し / fst m32 のみ | 2,022 | 2,019 | **1,783** | **1,764** | **1,774** |
| 無し / 無し / fst m64 のみ | 1,982 | 1,974 | 1,918 | 1,922 | 1,928 |
| 無し / 無し / 無し / fist | 5,676 | 5,661 | 5,636 | 5,645 | 5,661 |
| 算術のみ | 47,143 | 46,210 | **39,574** | 46,204 | 46,200 |
| 算術 / fst m32 のみ | 4,419 | 4,355 | 2,997 | 3,771 | 3,815 |
| 算術 / fst m64 のみ | 4,233 | 4,139 | 3,184 | 3,889 | 3,931 |

- **RC=1 (down) の不一致の大半は符号付きゼロ**: F・S が同じで V の差が ±0 の符号だけの試行は RC=1 で 7,916 件 (全組合せの合計)、RC=0/2/3 は各 2 件。 符号差の組ごとの内訳は未集計で、算術のみの組 (−6,636) に多く含まれると推定する。 IEEE 754 では x − x は round-toward-−∞ でだけ −0 になる。 数値の ulp は 0 だが bit 一致は失われる。
- RC=2/3 (up・trunc) の算術の減少は 6〜10 件と小さい。 RC=0 比の RC=1 の増分 11,068 件は、符号差の増分 約 7,914 件 (RC=1 の 7,916 件から RC=0 の 2 件を引く) と、実値の差の増分 約 3,150 件 (11,068 − 7,914 = 3,154) に分かれる。
- 対照の組 (RC で動く命令が無い) は RC によらず 20,180 で変わらない。 測定系が RC の変化で他の結果を変えないことの確認。
- fst m32 のみの組の減少は RC=1/2/3 で 236/255/245 件。 fst m32 の丸めは RC の影響を受ける (ADR D28 制限 (5) の記述と反する)。 この組は fst m64 と fist を含まないので、RC 由来の他の源は含まない。

## 4. 往復試験 (`x87_f80_rt.c`, `--roundtrip`, n = 100,000 per 類)

| 試験 | normal | exp_out_of_f64 | zero | inf | qnan | snan | denormal |
|---|---:|---:|---:|---:|---:|---:|---:|
| R1 f64→f80 (実 x87 と lowered の 10 byte) | 0 | — | 0 | 0 | 0 | **100,000** | 0 |
| R2 f80→f64 (実 x87 と lowered の double bits) | 0 | **2** | 0 | 0 | 0 | 0 | 0 |
| R3 f64→f80→f64 (lowered のみ) | 0 | — | 0 | 0 | 0 | **100,000** | 0 |
| R4 f80→f64→f80 (lowered のみ) | 99,944 | 100,000 | 0 | 0 | 99,948 | 100,000 | 100,000 |

(表の数字は不一致の件数 bad。 R1・R3 の exp_out は f64 の類に無い。)

- **R1・R3 の sNaN**: f64 の sNaN (quiet bit 51 = 0) は lowered の f64→f80 で sNaN のまま (quiet bit 62 = 0)。 実 x87 の `fldl` は quiet 化する。 R3 の lowered の往復では f80→f64 が quiet bit を立てるので bit が変わる。 NaN の quiet 化だけで、値は変わらない。
- **R2 exp_out の 2 件**: 指数が double の非正規域 (約 2^-1023〜2^-1074) に入る値の二重丸め。 `REPORT_APPENDIX_1099.md` §9 の「非正規域 22,660 件中 226 件」と同じ型と推定 (未検算)。
- **R4 の全件不一致**: f80→f64 で仮数が 64bit から 53bit に丸まる (normal の 11bit 失い)、qNaN の payload の下位 11bit が落ちる、指数域外は inf か 0、非正規は 0 に丸まる。 いずれも ADR D28 の制限 (精度・指数域) どおり。 f64 側の往復 (R3) は sNaN 以外で bit 一致。

## 5. 再現手順

```sh
cd tools/plugins/slayer_engine_ia32
python3 x87_diff.py --n 100000 --seed 1                  # 主 (native/lowered のビルドを含む)
python3 x87_diff.py --n 100000 --seed 1 --nega80         # m80 ネガコン
python3 x87_diff.py --n 100000 --seed 1 --nega           # 既存ネガコン
for r in 0 1 2 3; do python3 x87_diff.py --n 100000 --seed 1 --rc-arith $r; done   # RC 固定 (0 は基準)
python3 x87_diff.py --n 100000 --seed 1 --rc             # 旧 RC 試行
python3 x87_diff.py --n 100000 --roundtrip               # 往復 (R1〜R4)
python3 x87_crosscheck.py main                           # (a)(b)(c)。(d) は work/x87/rcarith0..3 を読む
```

生成物は `work/x87/` (gitignore)。 `x87_crosscheck.py` は試行と出力を直接読み、`x87_diff.py` の `compare()` を (d) の判定にだけ使う。 1099 §4 の有理数検算 (旧 `x87_crosscheck.py` (a)) は本 commit で置き換えた (旧版は commit `1adb69c3`)。
