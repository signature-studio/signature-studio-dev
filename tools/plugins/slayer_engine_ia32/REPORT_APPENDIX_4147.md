## 3. ecx の置き直し (受入条件 2) の実測

測定 (`X87_PROBE=1 python3 x87_fn_diff.py`、各 200 行または 4,000 行):

| 関数 | 行 | bit 一致 | 非自明性 (OBJ 窓が変わった行) | 判定 |
|---|---:|---:|---:|---|
| `0x10003fe0` (ecx = `0x10700000`) | 200 | 200 / 200 | 0 / 200 | 通る値。 書込みは `ecx+0x80174` 以降で窓 (0x540 B) の外 |
| `0x100051f0` (ecx = `0x10700000`) | 200 | 200 / 200 | 0 / 200 | 同上 |
| `0x1000a95a` (a0 = 窓の番地) | 4,000 | 4,000 / 4,000 | 0 / 4,000 | 窓を読むだけ (書かない) |

- `0x10003fe0`・`0x100051f0` は ecx 基底で本物の読みをするが、書込み先 (`[ecx+0x80174]` など) が窓の 0x540 B の外のため、OBJ 窓では変化が見えない。 非自明性の判定を通すには窓を広げる設計が要るので、本 issue の範囲では判定器を変えない。
- 値の一致は、native と wasm が同じ image・同じ ecx・同じ入力で同じ結果を返すことを示す。 wasm 側の模型 (ott_x87.h) の差分ではない。
- ゲート `python3 x87_fn_diff.py` は 7 本のまま PASS (exit 0)。
