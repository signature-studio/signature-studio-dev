### 12-1. key 8 の al=0 後段 (受入 1)

`0x1048457 test al,al; je 0x10485ec` (`0xffac50(chan)` = 0 のとき)。

- `0x10485ec`: lock・`[chan+0x258] = n` (`0x1048605`)・unlock・vtable `[rbx+8]` 呼出し (`0x1048636`)。`0x104865b` へ。
- `0x104865b`: flags `0x10` が無いので `je 0x1048702`。`0x1048702`: `[rbp+0x52e]` が 0 なら `0x1048795`。
- `0x1048795`: flags `0x4` が無いので `je 0x104a9ec`。
- `0x104a9ec` 以降 (`0x104aa19`・`0x104aa27`・`0x104aa41`・`0x104aa4e`・`0x104aa5f`・`0x104aa82`) の枝は、読んだ範囲で全て `0x104caae` に合流する。
- `0x104caae` → `0x104cb04`: `[rbp+0x52f]` と flags `0x40` の判定の後。
- `0x104cb04`: flags `0x100` が立つので `je 0x104cc2e` を取らず `0x104cb15`〜`0x104cc22` (格納のみ) を通って `0x104cc2e`。
- `0x104cc2e`: flags `0x80` が立つので `0x104cc3b` → `0x104cc60` → `0x104cc65`: `[rbp+0x584] = [rbp+0x5b8]` (clamp 後の n)。`0x104cc72` で ret。
- 結論: flags `0x3e9` (`0x100`・`0x80`・`0x20` を含む) で al=0 のとき、戻り値 = clamp 後の n。読んだ範囲で `0x10485ec`〜`0x104cc65` の間に `[rbp+0x5b8]` への直接の書換えは無い (`0x1048655` の書換えは flags `0x2` の枝で、`0x3e9` には `0x2` が無い)。

### 12-2. `0xffac50` の al 条件 (受入 2)

- 引数 rcx = chan (`0x104844b`)。戻り値 al = esi。
- 型 `t = [chan+0x160]` (dword)。`cmp eax,7; ja` (`0xffac65`・`0xffac68`) で `t ≤ 7` のときだけマスク判定。
  - マスク: `[0xffacd8]` のバイト = `0x32` (`.text` 内の静的値。実行時の書換えは未確認)。`1<<t` と AND して非 0 なら al=1 → 戻り値 0。
  - 値域: `t ∈ {1,4,5}` は戻り値 0 (マスク命中)。`t ∈ {0,2,3,6,7}` と `t ≥ 8` は走査へ (`0xffac82`・`0xffac8d`)。
- 走査: N = `len(G)` (`0x12f9ed0`。G = `[0x1964b60]`。`0x12f9ec0`・`0x12f9ed0` の RIP 相対で算出した同一の大域)。各 i ∈ [0,N) で `0xffaea0(chan,i)` ≥ 0 なら戻り値 1 (`0xffacb7`)。全 i で −1 なら 0。
- `0xffaea0(chan,i)`: `[chan+0x794] < 0` なら −1。そうでなければ O_i = G[i] (`0x12f9ec0`)。配列 A = `[O_i+0x21c74]` (長さ `[A-8]`) の各 `idx = A[k]` について、`[O_i+0xe0+idx*0x114] == [chan+0x794]` かつ `[O_i+0xd8+idx*0x114] == 3` なら idx を返す。無ければ −1。
- 要約: al(`0xffac50`) = 1 ⇔ `t ∉ {1,4,5}` かつ、ある i で O_i の表に `[chan+0x794]` と一致する type 3 の項目がある。
- 未確定: `[chan+0x160]` の型の意味、`[chan+0x794]` の意味、G と O_i の中身 (実行時の大域)。

### 12-3. key 8 の −1 を避ける条件 (受入 3)

key 8 の入口は、`0x1047100` から 700 命令の範囲では `0x1047604` (`sub 7`・`sub 1` が 0) の 1 本だけ (`grep 104839c` の結果)。flags `0x3e9` の key 8 で:

- `0x104847b` (`test 0x20; jne 0x104cc72`) の −1 は、al ≠ 0 のとき必ず出る (`0x3e9` は `0x20` を含み、`0x800` を含まないので `0x104846a` は抜けない)。
- al = 0 のときは `0x104847b` を通らず、12-1 の経路で n を返す。
- よって、key 8 について `0x104847b` の −1 を避ける条件 = `0xffac50(chan) == 0` (chan = `[rbp+0x4e8]`)。12-2 の言い方では「`t ∈ {1,4,5}` か、全 i で type 3 の一致が無い」。

### 12-4. 別の −1 出口 (`0x10471f9`、本節の受入外)

- `0x10471b0`〜`0x10471f9`: `cmp eax,8` (eax = key 下位 16bit) が一致し、かつ `0xffac50(chan')` ≠ 0 のとき `0x10471f9` で `jmp 0x104cc72` (−1)。
- chan' = `fe8bb0(*[0x59b07c], [rbp+0x55c])`、`[rbp+0x55c]` = key>>16 (`0x1047158`〜`0x104718c`。`[rbp+0x55c] ≥ 0` のとき `0x1047195` に入る)。
- この枝は `0x104847b` とは別の −1 出口で、key 8 は 2 本の −1 出口を持つ。`0x1047100` ブロックへの flags `0x3e9` からの到達性 (`0x104711f` の `[0x59b752]` 判定と `0x663bf0` の戻り値) は未読。
