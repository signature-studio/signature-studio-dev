# PY-219 (#3615): 0x1046a30 の [rbp+0x5b8] (cur) の経路上流と、[rbp+0x4e8] の基底・添字

親: #3476 (PY-203)。前段: `tools/python/REPORT_PY203.md` §1 (0x10485aa の ecx 式の上流の未確定)・`tools/python/REPORT_PY198.md` §2・`tools/python/REPORT_PY183.md` §2 (G = `[0x15e2218]` の items/count の用法)。
既知類型との関係: 該当なし (lift 作業ではない。PE の逆アセンブルによる解析)。

## 結論 (PE 実測で確定した範囲)

- **0x10485aa 直前の `[rbp+0x5b8]` (cur) = V = min(max(E, 0), 500)**。E は 0x1046a30 のエントリの第 2 引数 edx (`0x1046d6b` で `[rbp+0x5b8]` へ保存される値)。74 件の書込みのうち 0x10485aa へ届くのは 0x1048445 の clamp の 1 件だけ。
  - 上限 500 = `dword([[0x15e2198]])` − 2。静的な値は `0x14188a8` の dword 502 (`.data`)。0x15e2198 への RIP 相対の store は 0 件 (§4)。
  - 0x10483d3 の書込み (`0x40c660` = `cvtsd2si` で E × 1000/2^31 を丸めた値) は、0x10485aa への経路を取らない。経路条件 `[rbp+0x5c0] & 0x20 = 0` (0x104847b の `jne 0x104cc72`) が要る。`[rbp+0x5c0]` の値はエントリの第 3 引数 r8d。
- **0x10485aa の ecx = sgn(V − X)**、X = `[[rbp+0x4e8]+0x258]` (`0x104859a` の `[rbp+0x338]`)。0x104850f〜0x10485bb のループは |V − X| 回回り、ループ本体は `[rbp+0x5b8]` に書込まない。ループ入口 (0x10485bb→0x104850f) の到達集合は、ループの外と同じく 0x1048445 の 1 件 (§1)。
- **`[rbp+0x4e8]` の rax (0x10474d4 `mov rax, [rax+rcx*8]`)**: 基底 = `*(G + 8)` (G = `*[0x15e2218]`、配列の要素)、添字 = `movsxd [rbp+0x580]` = `(エントリの ecx) >> 16`。エントリ ecx は 0x1047456 の経路条件から `[0, 0x0fffffff]` なので添字は `[0, 0x0fff]`。境界検査 0x10474b6 は同じ G の `+0x10` (count) に対して行う。`[rbp+0x4e8]` の書込みは 0x10474d8 の 1 件。

## 0. 対象と前提

- 素材: `$ARTIFACTS_DIR/fl-win64.tar.zst` (2.3 GB) から `tar --zstd -xf ... --wildcards '*block00031_PE.bin'` で `$RUNNER_TEMP/fl-win64/extracted/block00031_PE.bin` を展開 (2.9 秒)。
- 対象: 0x1046a30〜0x104cf90 (25,952 B・4,904 命令。`pe_callgraph.py` の線形走査・int3 境界)。
- CFG: 即値の jmp/jcc のみ。間接 jmp は 0 件。境界に一致しない飛び先は 1 件 (0x104cdf8 → 0x104cdfa)。0x10485aa の先行閉包 (612 命令) に 0x104cdf8 は入らないので、結論に影響しない。
- 解析 (後ろ向き・順方向の到達解析) は逆方向の CFG 上で行う。経路条件 (フラグ・ecx) は手で追い、§1 の結論を確定する。

## 1. 受入 1: `[rbp+0x5b8]` の 74 件の書込みの分類と、0x10485aa での到達

| 分類 | 件数 | 書込み (代表) |
|---|---|---|
| 0x10485aa へ届く (他の書込みで殺されない) | 1 | 0x1048445 `mov [rbp+0x5b8], eax` (eax = `[rbp+0x348]` の clamp 結果) |
| 届くが 0x1048445 で殺される | 2 | 0x1046d6b `edx` (E)、0x10483d3 `eax` (0x40c660 の戻り値) |
| 0x10485aa への CFG 経路が無い | 71 | 0x1046d6b・0x10483d3 以外の 71 件 (値は `eax`・`ecx` の計算結果。0x1047706〜0x104b94e の別の分岐にあり、0x10485aa へ向かう経路の上に無い) |

- 逆方向到達解析 (書込みで止める): 0x10485aa の到達集合 = {0x1048445}。エントリまで書込み無しで届く経路は 0 件。
- 0x1048445 は 0x10485aa の全経路を支配する (0x1048445 を避ける後ろ向き経路はエントリに届かない)。
- 隠れた書込み: `lea r8, [rbp+0x5b8]` (0x104a924) は `[rbp+0x5b8]` のアドレスを取る唯一の箇所。渡し先 `call 0xc61250` (0x104a92b) は 0x1048445 を避ける経路に現れないので、0x10485aa に届く書込みではない (0x1048445 が毎回上書きする)。0xc61250 の中身は未読 (不要)。
- 0x1048452 `call 0xffac50` は rcx = `[rbp+0x4e8]` だけを渡す。`al ≠ 0` が 0x10485aa への経路条件 (未読)。`[rbp+0x5b8]` を書くポインタは渡さない。
- 0x10483ea (clamp の入力 W) の到達集合 = {0x1046d6b, 0x10483d3}。0x10483d3 の W' = RNE(E × 1000/2^31) は、`[rbp+0x5c0] & 0x20 ≠ 0` の経路だけで作られる。
  - `[rbp+0x5c0]` の到達集合 (0x1048476 でも 0x10485aa でも) = {0x1046d71 (r8d)} の 1 件。0x104a8a9 の `and ..., 0xffffffdf` は 0x10485aa に届かない。
  - 0x1048470〜0x104847b: `test eax, 0x20` が成立すると `jne 0x104cc72` へ抜ける (0x1048481 へ進まない)。0x104cc72 は 0x10485aa の先行閉包に入らない。よって W' の経路は 0x10485aa に届かない。
- clamp (0x10483ea〜0x104843f): s0 = max(W, 0) (`movsxd`・`jg` / `mov [rbp+0x348], 0`)。s0 ≤ A なら s0、そうでなければ B。A = `int32([[0x599d80]]) − 2`、B = `int32([[0x599d68]]) − 2`。`0x599d80` と `0x599d68` は同じ RIP 先 0x15e2198 (A = B = 500)。結果 V = min(s0, 500)。`[rbp+0x348]` の書込みは 3 件 (0x10483f6・0x104840a・0x1048438)。
- ループ (0x104850f〜0x10485bb): 本体 (0x104850f〜0x10485bb) の書込みは 0 件。`[rbp+0x580]` (ループ添字) だけが書かれる (0x10484f8・0x10485af)。

## 2. 受入 2: `[rbp+0x4e8]` の rax (0x10474d4)

- 命令: 0x10474bf `mov rax, [rip+0x59ad52]` → 0x10474c6 `mov rax, [rax]` → 0x10474c9 `mov rax, [rax+8]` → 0x10474cd `movsxd rcx, [rbp+0x580]` → 0x10474d4 `mov rax, [rax+rcx*8]` → 0x10474d8 `mov [rbp+0x4e8], rax`。
- 基底: `*(G+8)`、G = `*[0x15e2218]` (0x10474a6 の `[rip+0x59ad6b]` と 0x10474bf の `[rip+0x59ad52]` は同じ 0x15e2218)。REPORT_PY183 §2 の G (count = `[G+0x10]`、items = `[G+8]`) と同じ配列。
- 添字: `[rbp+0x580]` の到達集合 = {0x10474a0} の 1 件 (`mov [rbp+0x580], eax`、eax = `[rbp+0x5b0] >> 16`)。`[rbp+0x5b0]` の到達集合 = {0x1046d65 (ecx)} の 1 件。
- 経路条件: 0x10474a0 へは 0x1047456 (`jb 0x1047497`) からだけ届く。0x1047424〜0x1047451 の判定 (符号付きの `cmp 0x40000001`、`sub 0x80000000` の 2 回、`cmp 0x10000000`) から、エントリ ecx ∈ [0, 0x0fffffff]。添字 ∈ [0, 0x0fff]。
- 境界検査: 0x10474b6 `cmp ecx, [rax+0x10]` (rax = G)、0x10474b9 `jge 0x104cc72`。検査と参照は同じ G。
