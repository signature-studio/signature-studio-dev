# PY-181 (#3282): 効果関数 `0x1046a30` の n 書込み先の残り (key 下位 16bit 1・5〜7・9〜f、戻り値 eax、`0xffac50` の条件)

既知類型との関係: 該当なし (lift 作業ではない。PE の逆アセ解析)。親: #3252 (PY-175)。前段: `tools/python/REPORT_PY175.md` (key 0・2・3・4・8 と負の key 入口・`0x104aa87` の 0x1f00 枝を確定済み)。

## 結論

- 確定: key 下位 16bit の 1・5・6・7・9・0xa・0xb・0xc・0xd・0xe・0xf の書込み先 (表 1)。key 7 は n そのものではなく `n >= 0x20000000` の真偽を書く。key 0xd は `n / 定数` (double)、key 0xe は書込みではなく vtable 呼出し、key 0xf は `n / 定数` (double) を書く。
- 確定: 効果関数の戻り値 eax は、正常終端 (`0x104caae` → `0x104cc65`) では最終の n (`[rbp+0x5b8]`)。`0x104cc72` へ直接抜ける早期 exit では -1 (`0x1046d79` の初期値)。
- 確定: `0xffac50(chan)` が 0 を返す条件 (key 8 の書込みの条件)。`[chan+0x160]` の型が 8bit マスク (`byte [rip+0x5d]`) に入るときは常に 0、入らないときは要素を走査して 1 件でも `0xffaea0 ≥ 0` なら 1。
- 未確定 (子 issue へ): 負の key の残りの枝 (表 2)、key 0x10 以降の枝、`0x1050f90` の本体 (n → n1 → n2 の変換の出所)、`0xffaea0` と `0x12f9ed0` の本体。

## 3. 戻り値 eax と `0xffac50`

- 初期化: `0x1046d79` で `[rbp+0x584] = -1`。
- 早期 exit: `0x1046d8d` (`[0x59ab06]` の byte が非 0)、`0x10471f9` (key 範囲外の判定)、`0x10474b9`・`0x10495f6`・`0x1049621`・`0x104a7ba`・`0x104a7d0`・`0x104846a`・`0x104847b`・`0x10471f9` などは `jmp/jcc 0x104cc72` で、`[rbp+0x584]` は -1 のまま。
- 正常終端: `0x104caae` (負の key の終端 / 通常の末尾) → `0x104cc2e` → `0x104cc34` (flags `0x80`) → `0x104cc39` → `0x104cc65` で `[rbp+0x584] = [rbp+0x5b8]` (最終 n)。`0x104cc72` 以降で `eax = [rbp+0x584]` を返す。
- よって戻り値は、正常終端では最終 n、`0x104cc72` へ直接抜けた場合は -1。flags `0x3e9` の範囲で、どちらの経路を通るかは key ごとに異なる (表 1 の各枝は `0x104caae` か `0x104a9ec` を経由して末尾へ行く)。

`0xffac50(chan)` (key 8 の書込みの条件):

- `0xffac5f` で `eax = [chan+0x160]`。`eax > 7` なら `al = 0` (`0xffac82`)。
- `eax ≤ 7` なら `dl = 1 << (eax & 0x7f)`、`al = (dl & byte [rip+0x5d]) ≠ 0` (`0xffac73`〜`0xffac7d`)。`al ≠ 0` なら `esi = 0` で戻る (**戻り値 0**)。
- `al = 0` なら `0x12f9ed0` の件数 `eax` を回し、`0xffaea0(chan, i)` の戻り値が `≥ 0` になった時点で `sil = 1` (**戻り値 1**)。1 件も無ければ 0。
- 結論: 戻り値 0 ⇔ 型がマスクに入る、または要素の走査で 1 件も `0xffaea0 ≥ 0` が無い。key 8 の書込み (`[chan+0x258]`) は戻り値 0 のときだけ。
- 未確定: `0xffaea0` と `0x12f9ed0` の本体 (子 issue へ)。マスク `byte [rip+0x5d]` の実値は未実測。

## 4. `0x1050f90` (未読。子 issue へ)

- `0x1050f90` は `(ecx=n, rdx=out1, r8=out2)`。先頭で `lock(0x4232e0)` (`0x1050faf`) し、配列 `[[0x5938ad]+0x10]` の二分探索 (`0x1050fc4`〜`0x1051039`) で `[rcx+4]`・`[rcx+8]`・`[rcx+0xc]` を `out1`・`out2`・`rdi` に返す (`0x1051019`〜`0x1051023`)。
