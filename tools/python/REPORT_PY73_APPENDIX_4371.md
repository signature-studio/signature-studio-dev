## 1. `0xd1af20` の構造体経由の経路 (3965 §2 の続き)

`0xd16123`・`0xd16163` で `0xd1af20` を構造体 (`[rbp+0x30]`・`[rdx+0x30]`) に格納し、`0x526190` に渡す文脈は 3965 §2 を参照 (ここでは再掲しない)。

- `0x526190` は `[rbp+0x60]` に 16 byte (`movsq`×2) をコピーし、`0x525380` (引数 `r8` = そのコピー) と `0x525ec0` を呼ぶ。`0x525ec0` は `call qword ptr [rbx+0x18]` (間接 call、`rbx = [[rip+0x10cc721]]`) を含む。
- 所属: `0xd16123` は `0xd160e0` 内 (3965 §2 の func 推定)、`0xd16163` は `0xd16150` 内。`pe_callgraph.py callers 0xd16080,0xd160e0,0xd16150` の直接呼出し元は 3 関数とも 0 件 (本測定)。
- `0xd14800` の格納内容: `[0xd160e0, 0x525740, 0x100000000000e]` (`0xd1af20` ではなく `0xd160e0` を指す)。`0xd147d0` は `0xd16080` を格納。`0xd14800`・`0xd147d0` を読む RIP 相対・絶対参照は `.text` 全体で 0 件。

**未確定**: `0xd14800`・`0xd147d0` の読出し元 (間接経路の起点)。`0xd1af20` が `0x525ec0` の間接 call の標的になるかどうか。
