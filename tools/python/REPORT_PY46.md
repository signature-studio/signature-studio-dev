2. `0xd82c20` (入口〜末尾): 第 1 引数 `ecx` で分岐。
   - `0` のとき: 間接呼び出し `[rip+0x860485]` の戻り値が非 0 なら戻り値 0。
   - `>= 0` のとき: `0xc38bc0` を呼ぶ (`0xc38bc0` は `mov rax, [rip+0xa7f719]; ret` のみ = グローバル値の返却)。
   - `< 0` のとき: グローバル object の vtable `[rax+0x88]` を呼び、真なら `-1`〜`-8` 相当の分岐で固定文字列 (`lea rdx, [rip+...]`) を `0x4135e0` に渡し、最後に `0x414000` と vtable `[rbx]` の間接呼び出し。**文字列の中身は未読** (rdata の参照先を未確認)。
3. `0xd843d0` (共通ヘルパ): `[rbx+0x50]` が非 0 なら `0xd84f30` で判定。続けて `0xd841e0` でコマンド構造体を生成し、`0x4133f0` でフィールドを埋め、`0x526190` を呼ぶ。`0x526190` は `0x415610` → `0x525380` → `0x525ec0` (実行) → `0x415c30` (解放) の順。
4. `0xd841e0`: 引数 `rcx` を `dl` のフラグで `0x410320` 経由で変換し、`0x40f9e0`・`0x410360` を呼ぶ。`[rax+8]` に `r8` を書く。その後 vtable `[rbx-0x20]` の間接呼び出し。
