# PY-198 (#3442): 0x12a4450 の 6 呼出し元の ecx 出どころと、0x128f9e0 の cur index 書込み経路

親: #3403 (PY-195)。前段 `tools/python/REPORT_PY195.md` は main にも open PR にも存在しない (PY-195 を含む文書 0 件)。前段の確定値は使わず、PE を直接逆アセンブルして確定した。
既知類型との関係: 該当なし (lift 作業ではない。PE の逆アセンブルによる解析)。

## 結論 (PE 実測で確定した範囲)

- 表セル `0x15e26a0` (`.data`) の静的値は `0x193fa10` (8 バイト、file 上で確認)。`0x193fa10` は `.bss` の dword で、`[0x193fa10]` は表 `[0x15e06a0]` の添字 (cur index) として読まれる。
- 表セル由来のポインタで直接 store する命令は、`0x128f9e0` の内部で `0x12900d7` の 1 件、`0x12a4450` の内部で `0x12a458d` の 1 件。`0x12a4390` の内部には 0 件。**プログラム全体で「書込みは 2 箇所だけ」とは言えない** (表セル参照 247 件の分類は未了。#3477)。
- `0x12900d7` が書く値は `idx` = `[rbp+0x838]` = `0x128f9e0` のエントリの第 2 引数 `edx`。書込みに入るのは `0 ≤ idx ≤ 0x1f5` (符号付き) のときだけ。
- `0x12a458d` が書く値は `[rbp+0x3c]` の最後の書込み値。V1 (`0x12a4531` で保存した旧値) のまま、または `0x12a4390` が `0x12a4438` で書いた新しい index (`eax`) のどちらか。V1 と同じ値とは言えない。値域は未確定。
- 6 呼出し元の ecx の直接の式は 6 件とも確定 (§2)。引数の上流は 6 件すべて未追跡 (#3476)。

## 1. 受入 2: `0x128f9e0` の書込み直前の `[rbp+0x838]`

| VA | 命令 | 役割 |
|---|---|---|
| `0x128f9e9` | `mov rbp, rsp` | フレーム基準。`[rbp+0x838]` = エントリ rsp + 0x10 (第 2 引数の shadow) |
| `0x1290067` | `mov dword ptr [rbp + 0x838], edx` | **唯一の書込み** (`probe` で 1 件を確認) |
| `0x129007c`〜`0x129007f` | `test rax, rax`・`jl 0x1290090` | idx < 0 は書込み側に入らない (`0x1290090` は書込み無しの枝) |
| `0x1290081`〜`0x129008e` | `movsxd rax, [rbp+0x838]`・`cmp rax, 0x1f5`・`jle 0x12900bb` | idx > 501 も書込み側に入らない。書込み側 `0x12900bb` への飛び先は `0x129008e` だけ (probe) |
| `0x12900ca` | `mov rax, qword ptr [rip + …]` → セル `0x15e26a0` | 表セルの読出し |
| `0x12900d1` | `mov ecx, dword ptr [rbp + 0x838]` | 書込み値 |
| `0x12900d7` | `mov dword ptr [rax], ecx` | `[0x193fa10]` ← `idx` |

- `0x1290067` より前に call と `edx`/`rdx` の変更は無い (`around` の出力で確認)。よって `[rbp+0x838]` = **エントリの `edx`**。書込み側 (`0x12900bb`〜`0x12900d7`) に call は無い。
- `0x128f9e0` の直接呼出しは 60 箇所 (52 関数)。`pe_callgraph.py callers` が数えた直接 call (E8) だけで、間接 call (`call reg`・`call [mem]`) と `jmp` 経由は数えていない。各箇所の `edx` の出どころは未追跡 (§5)。
- `0x12900bb` は表セルを読んで `[rbp+0x59c]` へ保存するだけ (書込みではない)。

## 2. 受入 1: 6 呼出し元の ecx (`0x12a4450` の第 1 引数)

`0x12a4450` の先頭で `[rbp+0x90] = ecx`。`ecx == 0` なら `0x12a469a` へ抜けて何もせず戻る (`0x12a4475`)。以下は各呼出し直前の ecx 設定 (probe で照合済み)。

| # | 呼出し元 (関数先頭) | call VA | ecx の式 (設定命令) | 引数の上流 |
|---|---|---|---|---|
| 1 | `0x1021670` | `0x10219f8` | `ecx = eax`。eax は `call 0x45c290(&[rbp+0x30])` の戻り値 (`0x10219e0`) | 未追跡 (`0x45c290` の意味) |
| 2 | `0x1046a30` (cur 関数、PY-183 参照) | `0x10485aa` | `ecx = [rbp+0x338]` = sgn(`[rbp+0x5b8]` − `[[rbp+0x4e8]+0x258]`) (`0x104854d`〜`0x104859a`) | 未追跡 (`[rbp+0x5b8]`・`[rbp+0x4e8]`) |
| 3 | `0x1192f80` | `0x1193c45` | `ecx = sgn(edi − esi)` (`0x1193c1c`〜`0x1193c3e`) | 未追跡 (edi・esi) |
| 4 | `0x12ab520` | `0x12ab58b` | `ecx = [rdx+0x10]`。ただし `[rdx+8] == 8` の枝 (`0x12ab52c`〜`0x12ab549`) | 未追跡 (rdx = 第 2 引数) |
| 5 | `0x12ab710` | `0x12ab911` | `ecx = −sgn(r9d)` (`0x12ab8f0`〜`0x12ab90a`)。`r9d` は `esi` に保存 (`0x12ab71e`) | 未追跡 (第 4 引数) |
| 6 | `0x12acb70` | `0x12acbe7` | `ecx = [rbx+0x18]`。`rbx = rdx` (`0x12acb76`) | 未追跡 (rdx = 第 2 引数) |

- 6 呼出し元は `pe_callgraph.py callers` が数えた直接 call (E8) だけ。間接 call と `jmp` 経由の呼出しは数えていない。
- 符号の定義: `sgn(x)` は `x > 0` で 1、`x < 0` で −1、`x = 0` で 0。
- 6 件とも ecx の設定と call の間に ecx/rcx を書く命令は無い (probe の `between_ecx_writes=[]`)。
- ecx の値域は、2・3・5 が `{-1, 0, 1}`、1・4・6 は呼出し元の引数・構造体の値 (値域は未確定)。
- 引数の上流 (各関数の引数の出どころ) は 6 件すべて未追跡 (#3476)。

## 3. 受入 3: `[0x193fa10]` の書込み経路と値域

- 表セル由来のポインタで直接 store する命令 (probe の `cell_stores`: 分岐は両枝を辿り、`mov` による複製を追い、`call` に渡したものは `passed` に計上する走査): `0x128f9e0` は `0x12900d7` の 1 件、`0x12a4450` は `0x12a458d` の 1 件、`0x12a4390` は 0 件。`passed` (call への受け渡し) は 3 関数とも 0 件。
- 呼出し先の内部での書込みは数えていない。表セル参照は `.text` 全体で 247 件あり、その全件は分類していない。よって「書込みは 2 箇所だけ」は未確定 (#3477)。
- `0x12a458d` の経路: `0x12a4531` (V1 保存) → `0x12a4553`・`0x12a4571` で `call 0x12a4390` (`rcx = rbp`) → `0x12a4434` で `[0x193fa10] == esi` が成立すると `0x12a4438` で `[rbp+0x3c] = eax` → `0x12a458a`〜`0x12a458d` で `[rbp+0x3c]` を `[0x193fa10]` へ書き戻す。書込み値は V1 か `eax`。`eax` は `0x12a43f5` の剰余 + 1 で、値域は未確定。
- `0x12900d7`: 書く値は `idx`。`0 ≤ idx ≤ 0x1f5` のときだけ (§1)。
- 静的な初期値: `.bss` のため file に値は無い (ロード時 0 の前提)。
- 直接参照 (`pe_rip_refs.py 193fa10`): 6 件 (`0x12c1967`・`0x12c198d`・`0x12c2f5b`・`0x12c592f`・`0x12c6082`・`0x12c6224`)、全て読出し。
- `0x12a4390` の配列要素への書込み (`[rdx]`、`[rbx+0x40]` 側の 0x1f6 要素) が `0x193fa10` と重ならないことは未検査。
- `f8ca50` の (ii) 枝の tag 値域は**未確定**。`0xf8caa1` が同じセル `0x15e26a0` を読むことは確認 (PE の RIP 参照)。tag と `[0x193fa10]` の対応は未確認。
