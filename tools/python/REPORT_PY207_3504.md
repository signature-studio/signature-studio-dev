# PY-207 (#3504): K (0x16bacf0) の書込み経路の残件 (rep 宛先の由来・戻り値の領域ポインタの呼出し側・構造体の基底と大きさ)

親: #3443 (PY-199)。前段: `tools/python/REPORT_PY199_3443.md` (K への書込み 0 件・直接参照と別名追跡の結果)。本 REPORT は前段の数値を繰り返さず、残件の 3 点だけを扱う。
解析は `tools/python/analysis/flapi/pe_k_struct_probe.py` の ext A・B・C (本 PR で追加)。

## 結論 (検査した範囲)

- **K を覆う書込み: 0 件のまま** (前段と同じ。追加検査でも増えない)。
- rep 文字列の宛先 rdi を後ろ向きに深さ 3 まで辿った (250 件)。**領域 (`lea rip`・絶対即値) を宛先とするものは 0 件**。ただし由来が確定しない件数が 80 件残る (§1)。
- 戻り値の領域ポインタ 7 件を返す 2 関数の直接 call 元 18,335 箇所を、戻り値の別名で追った (深さ 0)。呼出し後の別名アクセス 2,528 件のうち K を覆うものは 0。領域内への書込みは 38 件で、いずれも K 以外の番地。bulk の宛先は K でない (§2)。
- 構造体の基底・大きさは確定しなかった。K 周辺の番地ごとの参照 (§3) は、K の直後にも個別の RIP 相対アクセスがあることを示す。
- 受入条件 3 点のうち、完全に満たしたものは無い。部分達成のため `Refs #3504`。

## 1. rep 文字列の宛先 rdi の由来 (ext A・受入 1)

後ろ向きの追跡 (直前 300 命令・深さ 3)。`mov reg, reg` と `lea reg, [reg+...]` は元のレジスタへ辿る。250 件の内訳 (`ext A` の出力そのまま):

| 由来 (ext A の分類) | 件数 |
|---|---|
| スタック (`lea` rbp/rsp 相対 83・`pop` 20・load-stack 系 130 のうち一部を含む合計) | 130 |
| 領域外の大域・即値 (`lea rip`・load-rip・imm。領域外と判定) | 6 |
| 領域 (`lea rip`・絶対即値・load-rip-region) | **0** |
| `insb`・`insd` (rep ins 系が rdi を書く) | 11 |
| ポインタの load・index 付き lea (追跡せず) | 17 |
| 演算 (`xor`・`add`・`sub`・`shr`・`imul`) | 5 |
| 深さ上限 (3) で停止 | 1 |
| 未確定: 300 命令内・連鎖内で rdi の書込みが見つからない | 80 |

- 領域を宛先とする rep は **0 件**。
- 未確定は **81 件** (未確定 80 件と深さ上限 1 件)。前段の 167 件 (粗い分類) からは減ったが、0 件にはならない。残件は #3504 に残す。

## 2. 戻り値の領域ポインタ 7 件の呼出し側 (ext B・受入 2)

- 関数 `0x412d60` は `0x16bab20`・`0x16bac58`・`0x16bac60` を返す。関数 `0x418190` は `0x16baaf8`・`0x16bab00`・`0x16bab08`・`0x16bac40` を返す。
- 両関数への直接 call 18,335 箇所から、戻り値 (rax) の別名を次の命令から追った (深さ 0。call 先の関数の中は追わない)。
- 呼出し後の別名アクセス 2,528 件。K を覆うもの 0 (読み 0・書込み 0)。領域内への書込み 38 件 (`0x16bab20`・`0x16bac40`・`0x16bac58`・`0x16bac60` 等。K ではない)。
- bulk (rep 文字列で rdi に別名を持つもの) 12 件。dst は全て `0x16bcaf8`。`0x119da2c` の `lea rdi, [rip + 0x51f0c5]` から計算すると領域外で、K ではない。
- **未了**: 呼出し側の先の関数の中は追っていない (深さ 0)。戻り値を別の関数へ渡す経路・スタック経由の再ロードは範囲外。

## 3. K 周辺の番地の並び (ext C・受入 3)

領域 `[0x16baaf0, 0x16bad20)` の番地ごとの参照 (d = 直接 disp32、a = 別名)。K と V・T 周辺のみ抜粋:

| 番地 | 参照 | 備考 |
|---|---|---|
| `0x16bacb8` | R8a・R8d | 基底候補 (前段 §4) |
| `0x16bacd8` | R8d・W8d | 表 T |
| `0x16bacec` | R4d・W4d | V |
| `0x16bacf0` | R4d | K (直接の読み 2 件) |
| `0x16bacfc` | R4d・W4d | K の直後 |
| `0x16bad00` | W8d | K の直後 |
| `0x16bad08`〜`0x16bad18` | R4d・W4d | K の直後 |

- K の直後 (`0x16bacfc`〜`0x16bad18`) も個別に RIP 相対で参照される。基底相対のアクセスからは並びが出ないため、大きさは静的に決まらない。
- **未了**: 構造体の大きさ (受入 3) は未確定。
