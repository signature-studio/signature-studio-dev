### 9.2 結論 (受入条件 1・2 の更新)

1. **観測の副作用を除いた比較 (受入条件 1): 未達**。ガード 0 (読出しあり) の ON では unit 158 が trap、ガード 1 (範囲確認あり) の ON では ok になる。ただしガード 1 でも同じ番地を読んでおり (st=3 が 0 件 = 範囲外で読み飛ばした箇所は無い)、「読出しの有無」は変数になっていない。実際に違うのは `rt.o` のビルド内容で、ガードの分岐が一度も成立しないのに trap が消える。したがって「観測の副作用が trap を起こした」とも「範囲確認で副作用を分離できた」とも言えない。ON の unit 158 の確定結果 (ok/trap) は得られていない。ガード 0/1 で trap の有無が変わり、差は実行経路の読出しではなく `rt.o` のビルド差に由来する可能性がある (未切り分け)。
2. **結論 (受入条件 2・意味的差かビルド差か観測副作用か)**: **未決のまま**。確定した点は次の 2 つ。(a) 「読出しが範囲外を踏んで trap を起こす」は否定された (st=3 が 0 件)。(b) 値差 (unit 158 j=12: OFF は `*dest`=NULL、ON は長さ 1 の文字列) はガード 0/1 の両方で残るため、ON で dest の値が変わる点は観測手段によらず再現する。ただし、この値が本物の挙動か、ON の C 転記版が別の値を書いた結果かは未切り分け。
3. **未切り分け点**: ガード 0/1 で trap の有無が変わる機構は未特定。ビルド差の仮説 (ガードの分岐を入れたまま判定だけ常に真にした build、または同じ `-D` で再ビルドした `rt.o` の再現性) と、読出し後の値の利用経路の確認 (IR と ON の C 転記版の突き合わせ) は本節では実施していない。この作業は子 issue の範囲とする (§9.3)。
4. **決定性 (受入条件 3)**: OFF 2 回で記録 227 件が完全一致。ガード ON も同一 build の 2 回で記録 227 件が完全一致 (指紋 `ac2d2efb758d4bb1`)。
