## 4. 検算・負の対照・限界

- **負の対照** (`bash tools/icall/diff/lea_index_scan_selftest.sh`・7/7 PASS):
  - 正: lea 基底 0x1813068c0 + rdx*8 + 0x10 は 0x1813068d0 に添字 0 で届く (届く・定数一致)。
  - 負 1: disp を 0x11 に壊すと候補 0 件。
  - 負 2: 添字を 1 にすると「届かない・定数不一致」。
  - 負 3 (B1): 分岐先を 0x 無し形式 (`je 180001011 <f+0x11>`) で書くと、境界になり 011 の候補は「届き得る」。前版 (`e1f253c2`) の走査では FAIL。
  - 負 4 (B2): 基底 rdx の定義が lea だけでも、je 経路は入口由来なので「届き得る」。前版では FAIL。
  - 負 5 (N1): `movsxd rax,ecx` は rax を上書きする。rax の候補は 0 件。`startswith("movs")` の判定 (前版) では候補 1 件となり FAIL を確認。
  - 正 2 (N1): string の `movs` は rdi を書く。rdi の候補は 0 件 (`== "movs"` にしても string は落ちない)。
- **レビュー側の独立試算**: `mnem == "movs"` の試作で、候補 1,256・届かない 205・届き得る 1,051 (本付録と同一)。
- **限界**:
  - 基底 X は、線形区間 (分岐先・ret/jmp/int3/ud2/hlt の直後で破棄) の lea 直値、または関数内の全定義が lea-rip の場合の集合に限る。`add`/`sub` で進めた基底は未追跡。
  - 流れ非依存の X は入口由来の経路を排除できない。判定は「届き得る」に限り、「届かない」にしない。
  - 添字の値域は、線形区間での最後の定義から分類する。分岐先は `JT_OP` で 0x の有無を問わず読む。直接分岐の先が全て拾えていることを前提にする。
  - 間接ジャンプの先は解析していない。間接分岐の先から入る経路は、基底・添字の値を追えない。
  - 関数入口の引数レジスタ (rcx・rdx・r8・r9 等) は、呼出し元の値を持たない (値域未確定)。
  - 暗黙の書込みの一部は未処理 (`cdqe`・`cwde`・`cbw`・`lods`・`lahf`・`xgetbv`・`xlat` の rax・rdx・rsi 等)。レビュー側の試作で件数差 0 を確認 (本付録では未検証)。
  - `movsxd` (レジスタ源) の値域 [−2^31, 2^31) は未分類 (値域未確定 251 件)。分類すれば 5 件に届く候補の一部は判定が変わり得る。
  - 別アルゴリズムによる検算は、レビュー側の試作 (§4 の独立試算) 以外は未実施。
