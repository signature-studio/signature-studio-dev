## 1. 結論

- **0x10c7850 の戻り値 (eax) の式を確定** (逆アセンブル + 実行で 11 ケース一致)。
  `v98 = min(v88, v90)` (両方 > 0 のとき。片方だけ > 0 ならその値。両方 ≤ 0 なら 0)、
  `ret = 0x7fffffff` (v98 == 0) / `low32(trunc(v98 - trunc(G)))` (それ以外)。
  `v88`・`v90` は 0x8e7e10 の戻り値、`G` は `*(*0x15e1608)` の double。
- **0 以下を返す入力**: `v98 > 0` かつ `trunc(v98 - trunc(G)) ≤ 0` (例: `v88 = 1.0, v90 = 3.0, G = 2.9` → -1。C7)。

- **6 入力の戻り値 0x7fffffff の意味**: 0x10c7850 の入口時点で `v88 = v90 = v98 = 0` (実測)。
  `v98 == 0` の分岐で sentinel を返すため、「両方の候補が 0 以下」の結果である。
