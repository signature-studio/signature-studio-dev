# GATES.md — 起動ゲート (ライセンス/ログイン/更新/ネットワーク/クラッシュ/WebView2 ほか) とスタブ方針

結論: 起動を **ブロックし得るゲートは 8 つ (G01–G08)**。いずれも (a) shim の戻り値だけで通せる (G01/G03/G05/G06/G07) か、(b) 仮想レジストリの既定値で回避できる (G02/G04/G08) もの。
**ネットワーク/認証/アップデート/WebView 系 (G09–G13) は起動時には発火しない** (遅延タイマー or ユーザ操作起点)。外部通信対象外方針により WinInet を常時「オフライン」にし、
FL が元々持つオフライン経路 (`error-offline.html`、"Not signed in"、Trial) をそのまま使う。FL 本体コードは変更しない。
根拠は STARTUP.md の各 VA。判定欄: **通す**=shim が成功を返す / **既定値**=仮想レジストリで回避 / **無効化**=機能ごと不使用 / **要実測**=lift 後に観察して確定。

## 補足 (事実整理のみ)

- ライセンス検査は単一関数ではなく、`MachineGuid`+`GetComputerNameExW`+Reg 系を読む同型コードが **24 関数にインライン展開**されている。同じ 24 関数は `SHFolder.dll` を `LoadLibraryW` で読み、`SHGetFolderPathW` を名前で解決して CSIDL 0x1a (AppData) で呼ぶ (IAT 直接の参照は持たない)。API・MachineGuid 文字列・SHGetFolderPathW の動的解決の 3 定義は同一の 24 関数 (`tools/startup/license_obs/REPORT.md` §9・付録 `REPORT_APPENDIX_107.md`)
  (例: `0xf2dbb0` 25 KB, `0x10c7cd0` 32 KB, `0x11dd800` 30 KB。難読化文字列 `hfg\`U`/`%s:%s:` を共有)。lift 後に**これらが同じ shim 面 (RegOpenKeyExA/RegQueryValueExW/GetComputerNameExW、および LoadLibraryW・GetProcAddress による SHGetFolderPathW の解決) を叩く**ことが
  スタブ要件。ライセンスの実効的な内容 (どの機能が Trial で制限されるか) は #107 (T11) で文字列が見える範囲を列挙済み (`tools/startup/license_obs/REPORT.md` §3.2)。lift 後の動的観測は FLEngine boot の突破待ち。
- 署名検査 (G03) は Authenticode の検証をバイパスする shim であり、Image-Line 署名物の改変を意味しない (WebStudio は wasm 再ビルド物のため署名自体が成立しない)。EULA 上の評価は行わない。
- `fl_api_user` / パスワード文字列が `CloudBounceConsole` の CLI 引数として engine に埋め込まれている (`0x95f9d0`)。Cloud Mastering は外部通信ゆえ対象外であり、この資格情報は使用しない。
- Gopher AI / FL Cloud / 認証は規約 (`docs/DECISIONS.md` D3) どおり対象外。上表の「無効化」はその実装方針。
