# pm — PM 運用ドキュメント

`docs/pm/` は **PM の運用**に関するファイルを置くディレクトリ。役割は 3 つだけ。

| ファイル | 役割 |
|---|---|
| [`DIRECTIVES.md`](DIRECTIVES.md) | 依頼者 (user) 指示の**逐語原文**。**依頼の正本**。新規指示はここに追記する |
| [`PREDECESSOR_ANALYSIS.md`](PREDECESSOR_ANALYSIS.md) | 解任された前任 PM セッション `ses_ee0c66629ffeZ92Uddt9mOoVur` の分析。混乱の原因と再発防止ルールへの反映 |
| [`RETRO_2026-10-13.md`](RETRO_2026-10-13.md) | Actions 移行後 2 日間のショートレトロ (依頼者指示 121)。事実・原因・対策 |

- **指示の逐語原文を 2 箇所に書かない。** 逐語は `DIRECTIVES.md` のみ。
  分析 (`PREDECESSOR_ANALYSIS.md`) は「前任者がどう解釈・実行したか」だけを扱い、原文は繰り返さない。
- 各ファイルの単一責任・「書いてはいけないもの」は **`docs/DOC_MAP.md` §4 が正本**。
