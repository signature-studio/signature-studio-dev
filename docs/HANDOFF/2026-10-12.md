## 6. ユーザ確定方針 (変更なき限り再掲)

逐語原文の正本は **`docs/pm/DIRECTIVES.md`** (本節はその要約)。

- FL 実物の **再コンパイル (lifter → wasm) ルートが第一目標**。スクラッチ再実装は不採用。
- プロプライエタリ plugin は解析 → wasm 同梱路線 (VST/CLAP をネイティブでホストする機構は優先度低)。
- 対象外: 外部通信 (Gopher AI / FL Cloud / 認証・ログイン)、OSS の *plugin* (Vital / Surge XT / Dexed)。
- OSS の *共有ライブラリ* (freetype/blend2d/ogg/ffmpeg/CPython 等) は upstream ソースから wasm 再ビルドし、lift しない。
- 目標 plugin: Serum 2 / Massive X (instrument)、OTT (最重視) / Fresh Air / Kilohearts (effect)。
- ライセンス機構の無力化・無条件アクティベーション (`docs/LEGAL.md` §6.0・`docs/DECISIONS.md` D2)。

## インシデント記録: opencode バイナリ削除 (2026-10-12)

- **発生日時**: 不明（2026-10-12 に発覚）
- **現象**: `~/.opencode/bin/opencode` が削除されていた
- **復旧**: 依頼者が手動で復旧済み。owner を `root:root` に設定し暫定的な再発防止を図っている
- **現状**: `opencode v2.0.27` が動作中

### 影響

opencode バイナリが消失すると、GitHub Actions の OpenCode ワークフロー (`.github/workflows/opencode.yaml`) とローカル CLI の両方が動作しなくなる。

### 原因（未確定）

削除がどのプロセスで発生したかは不明。当該日の作業（opencode workflow の修正・インストール周りの変更）との関連は未確認。

### 暫定対策

`root:root` 所有により一般ユーザーからの削除を防止。

### 恒久対策（PM 判断候補）

- GitHub Actions での opencode インストールは runner の一時ディレクトリ (`$RUNNER_TEMP`) に限定し、`$HOME` 配下には置かない（main の `.github/scripts/install-opencode.sh` は `$HOME/.opencode/bin` に置いている → `$RUNNER_TEMP` 配下に変更することを検討）
- ローカル CLI は `~/.opencode` を使わず、バージョン管理されたパス or `asdf`/`mise` 等で管理
- CI ジョブ内で `opencode` の uninstall/cleanup step が走らないことを確認
